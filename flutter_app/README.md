# دليل بناء تطبيق أندرويد APK لتفسير السيد العلامة بدر الدين الحوثي (أوفلاين 100٪)

هذا الدليل يشرح لك كيفية إعداد مشروع Flutter وبناء ملف الـ APK الخاص بالهاتف المحمول لقراءة واستعراض ملف التفسير المضغوط `tafsir.json.gz` والذي سيعمل محلياً بالكامل وبدون الحاجة لإنترنت.

---

## 🛠️ متطلبات الإعداد المسبق

تأكد من تنزيل وتسطيب المكونات التالية على جهاز الكمبيوتر الخاص بك:
1. **Flutter SDK** (الإصدار 3.0.0 أو أحدث).
2. **Android Studio** أو **VS Code** (مع تسطيب إضافتي Flutter و Dart).
3. ملف التفسير المضغوط `tafsir.json.gz` بحجم تقريبي 3.2MB.

---

## 📂 خطوات إعداد وهندسة المشروع

### 1. إنشاء مشروع Flutter جديد
افتح محطة الأوامر (Terminal) في جهاز الكمبيوتر الخاص بك واكتب الأمر التالي لإنشاء المشروع:
```bash
flutter create al_furqan_tafsir --org com.alfurqan.tafsir
cd al_furqan_tafsir
```

### 2. تجهيز ملف الإعدادات `pubspec.yaml`
استبدل المحتوى الافتراضي لملف `pubspec.yaml` في مشروعك بالمحتوى التالي لتضمين الإضافات المسؤولة عن فك ضغط الملفات المضغوطة وتحديد مسار الوصول في نظام الهاتف:
```yaml
name: al_furqan_tafsir
description: "تطبيق الفرقان الأوفلاين لقراءة واستعراض تفسير تيسير التفسير لعلامة القرن السيد بدر الدين الحوثي."
publish_to: 'none'
version: 1.0.0+1

environment:
  sdk: '>=3.0.0 <4.0.0'

dependencies:
  flutter:
    sdk: flutter
  archive: ^3.3.7
  path_provider: ^2.1.1
  cupertino_icons: ^1.0.5

dev_dependencies:
  flutter_test:
    sdk: flutter
  flutter_lints: ^2.0.1

flutter:
  uses-material-design: true
  assets:
    - assets/tafsir.json.gz
```

### 3. إعداد واستيراد ملف البيانات `tafsir.json.gz`
- قم بإنشاء مجلد جديد في جذر مشروعك باسم `assets`.
- انسخ ملفك المسمى `tafsir.json.gz` وضعه داخل هذا المجلد ليكون كالتالي:
  `al_furqan_tafsir/assets/tafsir.json.gz`

*تنبيه هام ومحوري:* يجب أن يكون هيكل مصفوفة الـ JSON داخل الملف المطابق تماماً للبنية التالية:
```json
{
  "سورة الفاتحة": {
    "1": "توضيح وتفسير الآية الأولى...",
    "2": "تفسير الآية الثانية..."
  },
  "سورة البقرة": {
    "1": "توضيح آيات الإرشاد والتنزيل..."
  }
}
```

### 4. كتابة شيفرة التطبيق الأساسية `lib/main.dart`
استبدل محتويات الملف `lib/main.dart` في مشروعك بالنسخة المرفقة في مجلدنا (`/flutter_app/main.dart`). هذه النسخة تقوم بالمهام التالية:
- التحقق عند أول إقلاع للتطبيق من وجود قاعدة البيانات غير المضغوطة في الهاتف.
- في حال عدم وجودها، يقوم بفك الضغط السريع عن ملف `tafsir.json.gz` وحفظ النسخة المفكوكة محلياً كمسودة كاش سريعة (`tafsir_cache.json`) لتجنب تكرار فك الضغط في المرات القادمة ودعم سرعة فتح فائقة.
- استعراض ديناميكي كامل لـ 114 سورة عبر Dropdown وتلقي رقم الآية وتثبيته.

## ⚡ أوامر المزامنة وتشغيل التطبيق

بمجرد تجهيز الملفات ومطابقة الهياكل أعلاه، يمكنك تنفيذ الأوامر التالية في مجلد مشروعك لتشغيل التطبيق أو إصدار ملف APK للتشغيل المباشر:

### تنزيل وتثبيت إضافات المشروع:
```bash
flutter pub get
```

### تشغيل التطبيق في وضع المطورين للتأكد (Development Mode):
```bash
flutter run
```

### بناء ملف الـ APK النهائي والجاهز للتثبيت على الهواتف:
```bash
flutter build apk --release
```

بمجرد اكتمال البناء بنجاح، ستجد ملف الـ `app-release.apk` الجاهز للتوزيع والتثبيت في المسار التالي داخل مجلد مشروعك:
`build/app/outputs/flutter-apk/app-release.apk`

## 💡 توجيهات أمان واستقرار الأداء:
1. **عدم جلب تفسير براني:** الكود مهيأ ليعتمد محلياً بنسبة 100% على المدخلات القادمة من ملفك المرفق فقط ولن يقوم باستجلاب أي تفاسير من خوادم الذكاء الاصطناعي أو الويب الخارجي.
2. **منهجية التيسير:** الكود يستخلص ويعرض بيانات التفسير الموقعة أمام الآية المحددة بالتمام والكمال دون تحوير أو تعديل بقدسية وأمانة علمية عالية.
3. **دعم اللغة العربية:** تم تهيئة التطبيق برمجياً ليعمل بالاتجاه الأيمن (RTL) بشكل افتراضي وذاتي متطابق مع واجهات خطوط "Cairo" لانسجام بصري مريح أثناء القراءة والتأمل.
4. **شريط التحكم بحجم الخط:** يتضمن التطبيق شريط تمرير (Slider) ديناميكي يتيح تكبير أو تصغير حجم خط التفسير من 14 إلى 32 نقطة لتسهيل القراءة وتوفير راحة مثالية لكبار السن وضعاف البصر.
